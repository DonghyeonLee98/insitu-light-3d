# in situ 광원 3D (470 / 940 nm 광섬유 조명)

빔라인 in situ 측정에 가져갈 470·940 nm 두 채널 LED 광섬유 조명의 3D 배치. 부산대 이동현, 2026-10-11 설계(10-12 뷰어).

- 보기: [한국어](https://donghyeonlee98.github.io/insitu-light-3d/) · [English](https://donghyeonlee98.github.io/insitu-light-3d/en.html) · [English, 가벼운 판(휴대폰)](https://donghyeonlee98.github.io/insitu-light-3d/en-lite.html)
- 전체·입력·출력 보기, 끌어서 회전·확대, 내부 보기, 분해 보기. 부품을 누르면 실제 크기(mm), 제조사 링크, 배치 가정이 나온다.
- 구성: 470/940 nm LED 두 채널, LED 드라이버 LEDD1B, 전원(KPS201은 외형 예시), 입력 결합, 2 m 광섬유, 출력 헤드, 10×10 mm 활성면.
- 가정: 시료 기판·받침·기둥·클램프는 임시 제안이다. 렌즈 초점거리는 633 nm 명목값으로 잡은 초기값이라, 470/940 nm 초점·광량·균일도는 실측으로 맞춘다. 표시한 광선은 광축이며 광선 추적 결과가 아니다.
- 부품 형상은 제조사(Thorlabs 등)가 공개한 CAD를 배율 그대로 배치했다. 제조사 원본 STEP/PDF는 이 저장소에 넣지 않았다.
